# factory_line_ops

Search-head app: dashboards, KV Store, and alerts for Factory Line Operations.

Install `TA-factory_line` first. Do not enable scheduled searches until indexes and HEC are in place (`enableSched` ships as 0).

Icons in `appserver/static/` (`appIcon.png`, `appIcon_2x.png`, `appLogo.png`, and alt variants) are original Factory Line Operations marks. Rebuild with `python3 scripts/generate_icons.py` from the product root.
